# 回文检测器

一个简单的命令行回文检测程序。  
输入一句话，程序会清理标点、空格并忽略大小写，然后判断它是否为回文。

## ✨ 功能特性

- 输入任意文本（支持中英文）
- 自动清理标点、空格和特殊符号
- 忽略大小写
- 判断清理后的文本是否为回文
- 输出清理后的文本和判断结果
- 无需第三方依赖，仅使用 Python 标准库

## 🧠 逻辑说明

程序主要分为两步：

1. **清理文本**  
   默认使用正则 `re.sub(r'[^\w]', '', text).lower()`：  
   - `\w` 在 Python 中默认匹配 Unicode 单词字符，包括字母、数字、下划线以及中文等字符  
   - `[^\w]` 表示去掉所有非单词字符（标点、空格等）  
   - `.lower()` 统一转为小写，忽略大小写差异  

   也可以使用 `use_regex=False`，此时改用 `ch.isalnum()` 逐个字符判断，只保留字母和数字，不保留下划线。

2. **判断回文**  
   将清理后的字符串与其反转字符串比较：  
   ```python
   cleaned == cleaned[::-1]
   ```
   如果相等，就是回文；否则不是。

## ⚙️ 函数说明

### `clean_text(text, use_regex=True)`

- **参数**：
  - `text`：待清理的文本
  - `use_regex`：是否使用正则清理，默认 `True`
- **返回**：清理并转为小写后的字符串

### `is_palindrome(text)`

- **参数**：`text`：待检测文本
- **返回**：`(bool, str)`，即 `(是否为回文, 清理后的字符串)`

### `main()`

- 读取用户输入
- 调用 `is_palindrome`
- 打印清理结果和判断结果

## ⚠️ 注意事项

- 输入为空字符串时，清理后仍为空，空字符串通常视为回文（`"" == ""`）。
- 默认使用正则 `\w`，会保留下划线 `_`；如果不想保留下划线，可以设置 `use_regex=False`。
- 中文、日文等 Unicode 字母会被保留，标点和空格会被去除。
- 程序不处理多行输入，一次只检测一行。
