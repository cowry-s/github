# 回文检测器 (Palindrome Checker)

一个简单的 Python 脚本，用于判断一句话或一段文本是否为回文。  
它会自动忽略标点、空格、大小写，并支持中文、英文和数字。

## 功能特性

- 支持中英文及数字混合文本
- 自动忽略标点符号、空格、下划线等非字母数字字符
- 忽略大小写
- 提供两种清理方式：
  - 正则表达式（默认，支持 Unicode）
  - `str.isalnum()` 逐字符判断
- 对空输入或纯标点输入给出友好提示
- 可直接运行，也可作为模块导入使用

## 环境要求

- Python 3.6 或更高版本
- 无需安装第三方库

## 使用方法

### 1. 直接运行脚本

将代码保存为 `palindrome.py`，然后在终端运行：

```bash
python palindrome.py
