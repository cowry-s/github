# 学生成绩管理系统

一个基于命令行的学生成绩管理程序，使用 CSV 文件存储数据。  
支持添加、删除、修改、查询和显示学生成绩，数据持久化到本地 CSV 文件。

## ✨ 功能特性

- 显示全部学生记录
- 添加学生（学号、姓名、成绩）
- 删除学生（按学号）
- 修改学生信息（姓名、成绩）
- 查询学生（按学号或姓名关键字）
- 数据保存到 CSV 文件，支持中文
- 输入校验：学号非空、姓名非空、成绩 0–100
- 启动时自动加载已有数据，退出时自动保存


## 🚀 快速开始

### 环境要求

- Python 3.6 或更高版本
- 无需第三方依赖，仅使用标准库（`csv`、`os`）

### 运行方式

```bash
python main.py
```

启动后会显示菜单：

```
===== 学生成绩管理 =====
1. 显示全部
2. 添加学生
3. 删除学生
4. 修改学生
5. 查询学生
6. 保存并退出
请选择 (1-6):
```

## 📖 菜单说明

### 1. 显示全部

以表格形式列出所有学生：

```
学号       姓名       成绩  
------------------------------
1001       张三       85.0  
1002       李四       92.5  
```

### 2. 添加学生

依次输入学号、姓名、成绩。  
如果学号已存在，会提示“该学号已存在”。  
成绩必须在 0 到 100 之间。

### 3. 删除学生

输入要删除的学号，若存在则删除并保存。

### 4. 修改学生

输入要修改的学号，显示当前信息。  
姓名和成绩可以留空表示保持不变。  
成绩同样会校验 0–100 范围。

### 5. 查询学生

输入学号或姓名的关键字（不区分大小写），列出所有匹配记录。

### 6. 保存并退出

将当前数据写入 `students.csv` 并退出程序。

## 📄 数据文件格式

程序使用 `students.csv` 存储数据，编码为 `utf-8-sig`（带 BOM，方便 Excel 打开中文）。

表头固定为：

```csv
id,name,score
1001,张三,85.0
1002,李四,92.5
```

字段说明：

| 字段 | 含义 | 说明 |
|------|------|------|
| id   | 学号 | 唯一，不能为空 |
| name | 姓名 | 不能为空 |
| score| 成绩 | 0–100 的浮点数 |

> 首次运行程序时，如果 `students.csv` 不存在，会自动创建。  
> 也可以手动准备一个 CSV 文件，只要表头正确即可。

## ⚠️ 注意事项

- 学号是唯一标识，重复添加会失败。
- 成绩输入必须是数字，且范围在 0–100。
- 修改时留空表示不修改该项。
- 所有修改在退出或执行保存操作后写入文件。
- 如果 CSV 文件损坏或格式错误，程序会提示读取失败，但不会崩溃。
