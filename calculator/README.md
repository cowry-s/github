# 简易计算器

一个支持四则运算的命令行计算器，附带单元测试。  
支持加、减、乘、除，带输入校验和除零保护。

## ✨ 功能特性

- 支持加（`+`）、减（`-`）、乘（`*`）、除（`/`）四种运算
- 输入校验：非数字输入会提示重新输入
- 除零保护：除以 0 时抛出 `ValueError`，程序捕获并友好提示
- 支持连续计算，按 `y` 继续、其他键退出
- 函数拆分清晰，便于测试与复用
- 附带 `unittest` 单元测试

## 🚀 快速开始

### 环境要求

- Python 3.6 或更高版本
- 无需第三方依赖，仅使用标准库

### 运行方式

```bash
python calculator.py
```

启动后会进入交互模式：

```
=== 简易计算器 ===
支持操作: +, -, *, /
请输入第一个数字: 10
请输入运算符 (+, -, *, /): /
请输入第二个数字: 2
结果: 10.0 / 2.0 = 5.0
是否继续计算？(y/n): n
感谢使用，再见！
```

## 📖 函数说明

### `add(x, y)`

返回 `x + y`。

### `subtract(x, y)`

返回 `x - y`。

### `multiply(x, y)`

返回 `x * y`。

### `divide(x, y)`

返回 `x / y`。  
如果 `y == 0`，抛出 `ValueError("除数不能为零")`。

### `get_number(prompt)`

循环读取用户输入，直到输入是合法数字，返回 `float`。

### `main()`

主循环：读取两个数字和运算符，执行对应运算，打印结果，询问是否继续。

## 🧪 运行测试

```bash
python -m unittest test_calculator.py
```

或使用发现模式：

```bash
python -m unittest discover
```

测试覆盖：

- `add`：正数相加、正负相加
- `subtract`：基本减法
- `multiply`：基本乘法
- `divide`：正常除法、除以零抛出 `ValueError`

## ⚠️ 注意事项

- 输入必须是数字，否则 `get_number` 会提示重新输入。
- 运算符只支持 `+`、`-`、`*`、`/`，其他符号会提示“不支持的运算符”。
- 除以 0 会触发 `ValueError`，主循环捕获后打印 `错误: 除数不能为零`，不会崩溃。
- 结果以浮点数显示（例如 `10 / 2 = 5.0`）。
- 退出条件：在“是否继续计算？”处输入非 `y` 的任意字符。
