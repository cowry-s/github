# 猜数字游戏

一个简单的命令行猜数字游戏。  
程序随机生成一个 1 到 100 之间的整数，玩家通过不断猜测，根据提示缩小范围，直到猜中为止。

## ✨ 功能特性

- 随机生成 1–100 的整数
- 输入校验：只接受正整数
- 范围校验：数字必须在 1–100 之间
- 实时提示“太大了”或“太小了”
- 猜中后显示答案和总猜测次数
- 无需第三方依赖，仅使用 Python 标准库

## 🚀 快速开始

### 环境要求

- Python 3.6 或更高版本
- 无需安装任何第三方库

### 运行方式

```bash
python guess_number.py
```

启动后会看到欢迎信息，然后进入猜数字循环：

```
🎮 欢迎来到猜数字游戏！
我已经想好了一个 1 到 100 之间的整数。
请输入你的猜测: 
```

## 🎮 游戏规则

1. 程序随机生成一个 1 到 100 之间的整数。
2. 玩家输入一个猜测数字。
3. 如果输入不是正整数，提示重新输入。
4. 如果数字不在 1–100 范围内，提示重新输入。
5. 每次有效猜测后，程序会提示：
   - `📉 太大了，再小一点。`
   - `📈 太小了，再大一点。`
6. 猜中后显示答案和总次数，游戏结束。

## 🧠 函数说明

### `guess_number()`

主游戏函数，包含：

- 使用 `random.randint(1, 100)` 生成随机答案
- 使用 `while True` 循环接收输入
- 使用 `str.isdigit()` 验证是否为正整数
- 使用 `int()` 转换并判断范围
- 根据比较结果给出提示
- 猜中后打印答案和尝试次数并退出循环

### `if __name__ == "__main__":`

确保脚本被直接运行时才启动游戏，方便作为模块导入。

## ⚠️ 注意事项

- 输入必须是正整数，不能是小数、负数或字母。
- 数字范围限制在 1–100，超出会提示重新输入。
- 每次运行都会生成新的随机答案。
- 程序不记录历史成绩，关闭后不会保存。
- 如果想中途退出，可以按 `Ctrl + C` 终止程序。
