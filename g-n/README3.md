# 猜数字游戏 (Number Guessing Game)

一个简单的 Python 命令行小游戏。程序会随机想一个 1 到 100 之间的整数，玩家通过不断猜测来找出这个数字。每次猜测后，程序会提示“大了”或“小了”，直到猜中为止，并统计总共猜了多少次。

## 功能特性

- 随机生成 1–100 之间的整数
- 支持多次猜测，直到猜中
- 实时提示“大了”或“小了”
- 输入验证：
  - 自动去除首尾空格
  - 拒绝非整数输入
  - 拒绝超出 1–100 范围的数字
- 猜中后显示答案和总猜测次数
- 纯标准库实现，无需安装第三方依赖

## 环境要求

- Python 3.6 或更高版本
- 无需安装任何第三方库

## 使用方法

### 直接运行脚本

将代码保存为 `guess_number.py`，然后在终端运行：

```bash
python guess_number.py
